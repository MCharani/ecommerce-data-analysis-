# E-Commerce Sales Analysis

## About the Project
Analyzed retail sales data using Python and Power BI to understand sales trends, product performance, and customer purchasing patterns.

## Tools Used
- Python
- Pandas, NumPy
- Matplotlib
- Jupyter Notebook
- Power BI

## Key Insights
- Total Revenue: 456,000
- Total Transactions: 1,000
- Average Transaction Value: 456
- Electronics generated the highest revenue.
- May recorded the highest monthly revenue.

## Features
- Data cleaning and exploratory data analysis using Python.
- Sales analysis by product category, gender, and age group.
- Monthly revenue trend analysis.
- Interactive Power BI dashboard.

## Project Structure
- `data/` – Dataset
- `notebooks/` – Python analysis notebook
- `dashboard/` – Power BI dashboard
- `visuals/` – Charts and visualizations
